Caption:
Fig. X. Closed-loop signal flow of the nonlinear C-EPS assist-map controller.

Layout:
The forward path follows the component-by-component convention of Seborg et
al., Process Dynamics and Control, 4th ed., Fig. 11.7 (PDF p. 190). Measured
signals return along the lower paths. The block style and separate physical
signals follow Fig_Plant_internal.drawio. Every wire carries one signal. A dot
marks a branch of the same signal; plain crossings are not connections.

Controller and final control element:
The torque sensor returns T_s,m and the speed sensor returns v_m. The static
assist map M(v_m,T_s,m) produces T_map. The lead-lag compensator C_map(s)
produces T_a,cmd. The speed-dependent assist limit L(T_a,cmd,v_m) produces
T_a,lim; the motor G_a(s) produces the applied assist torque T_a.

Plant and measurements:
The nonlinear coupled plant receives T_a and the independent physical inputs
theta_1 (driver angle), v (true speed), and mu (road friction). Its true
steering-torque output is T_s. The branch from true speed v also supplies the
speed sensor. Only the output required for this control loop is shown. The
assist map has no set point or error comparator.

Notation:
C_map(s) and G_a(s) name dynamic blocks. The whole nonlinear plant is a
state-space operator, not a global transfer function. Fig. 11.7's additive
disturbance-output decomposition is therefore not applied to this plant.
