6. COMMIT (TỰ ĐỘNG, CHỈ FILE CỦA MÌNH)
  KHÔNG dùng tools/sync_repo.sh: nó chạy git add -A nên sẽ commit cả việc dở của khung khác (khung PAPER đang có hình và file chưa commit, khung kia đang chạy song song). Thay bằng, ở gốc
    repo, Git Bash:
    git add -- <đúng các đường dẫn ở mục 1 của khung mình>
    git commit -m "[PC] VDB_<BODY/TIRE>: thử đổi từng cổng (<số ca ĐẠT>/<tổng>), <số PHÁT HIỆN> phát hiện" -m "Co-Authored-By: <dòng ghi công theo nhắc của hệ thống>"
    git pull --rebase --autostash origin main
    git push origin main
  Lỗi "index.lock" hay push bị từ chối vì khung kia vừa push: chờ khoảng 30 s bằng một lệnh kiểm rồi chạy lại từ git pull, tối đa 3 lần. Xung đột khi rebase (không nên có vì hai khung ghi file
    khác nhau): git rebase --abort, DỪNG, báo người dùng. Không dùng --force, không --no-verify. Không commit file .mat (đã trong .gitignore) và không commit scratch/.
  Máy không phải PC (hostname khác DESKTOP-G6T192V) thì thay [PC] bằng [laptop]. Tracking/repo_history.md để khung COMMON sinh lại sau.
