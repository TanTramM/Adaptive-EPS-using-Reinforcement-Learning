3.4. HỆ PHƯƠNG TRÌNH KHÔNG GIAN TRẠNG THÁI TỔNG QUÁT BẬC 4 CỦA HỆ THỐNG C-EPS VÀ THÂN XE
================================================================================

3.4.1. Định nghĩa Vector Trạng thái, Biến Điều khiển và Tín hiệu Nhiễu
--------------------------------------------------------------------------------
Hệ thống động lực học vòng kín kết hợp giữa Cột lái C-EPS, Lốp Pacejka và Thân xe 2 bậc tự do được mô tả tổng hợp bằng hệ phương trình vi phân phi tuyến bậc 4.

1. Vector 4 biến trạng thái liên tục x(t) ∈ ℝ⁴:
   x(t) = [ x₁(t)  x₂(t)  x₃(t)  x₄(t) ]ᵀ = [ θ(t)  θ̇(t)  β(t)  γ(t) ]ᵀ

   Trong đó:
   * x₁(t) = θ(t): Góc xoay vô-lăng (rad).
   * x₂(t) = θ̇(t): Vận tốc góc xoay vô-lăng (rad/s).
   * x₃(t) = β(t): Góc trượt hông thân xe tại trọng tâm CG (rad).
   * x₄(t) = γ(t): Vận tốc góc Yaw quay quanh trục đứng thân xe (rad/s).

2. Biến điều khiển đầu vào u(t) ∈ ℝ¹:
   u(t) = T_a(t)  (Mô-men trợ lực do motor cấp, N·m)

3. Biến nhiễu ngoại cảnh tác động w(t) ∈ ℝ¹:
   w(t) = T_d(t)  (Mô-men bẻ tay do tài xế tác dụng lên vành vô-lăng, N·m)


3.4.2. Hệ phương trình phụ đại số liên kết trung gian
--------------------------------------------------------------------------------
Trước khi lập hệ phương trình trạng thái, các biến lực và mô-men trung gian được tính toán từ vector trạng thái x(t) thông qua các phương trình phụ đại số:

1. Góc trượt lốp trước (α_f):
   α_f(x₁, x₃, x₄) = x₃(t) + (l_f × x₄(t) / v) - (r_p / l_am) × x₁(t)

2. Lực bên lốp trước phi tuyến Pacejka (F_yf):
   F_yf(α_f) = D_f × sin( C_f × arctan( B_f × α_f - E_f × ( B_f × α_f - arctan(B_f × α_f) ) ) )
   (với D_f = μ × F_zf,  F_zf = (m × g × l_r) / [ 2 × (l_f + l_r) ])

3. Lực bên lốp sau tuyến tính (F_yr):
   F_yr(x₃, x₄) = C_r × [ - x₃(t) + (l_r × x₄(t)) / v ]

4. Mô-men cản phản lực mặt đường dội ngược thước lái (T_r):
   T_r(α_f) = K_tr × F_yf(α_f) = [ (2 × r_p × (t_p + t_m)) / l_am ] × F_yf(α_f)


3.4.3. Hệ phương trình vi phân không gian trạng thái phi tuyến đầy đủ
--------------------------------------------------------------------------------
Tổng hợp từ 3 cụm động lực học (Cột lái, Lốp Pacejka và Thân xe 2-DOF), hệ 4 phương trình vi phân trạng thái bậc nhất mô tả chuyển động toàn cục của hệ thống được viết như sau:

(1)  dx₁/dt = x₂(t)

(2)  dx₂/dt = [ T_d(t) + T_a(t) - B_total × x₂(t) - T_f,total × tanh(c × x₂(t)) - T_r(α_f) ] / J_total

(3)  dx₃/dt = [ F_yf(α_f) + C_r × ( - x₃(t) + (l_r × x₄(t)) / v ) ] / (m × v) - x₄(t)

(4)  dx₄/dt = [ l_f × F_yf(α_f) - l_r × C_r × ( - x₃(t) + (l_r × x₄(t)) / v ) ] / I_z


3.4.4. Biểu diễn dạng không gian trạng thái chính chính tắc ẋ = f(x) + B_u·u + B_w·w
--------------------------------------------------------------------------------
Tách riêng các thành phần động lực học nội tại phi tuyến f(x) với các biến tác động đầu vào u(t) = T_a(t) và w(t) = T_d(t):

  dx/dt = f(x) + B_u × T_a(t) + B_w × T_d(t)

Trong đó:

1. Vector hàm động lực học phi tuyến nội tại f(x):
          ┌                                                                            ┐
          │                                   x₂                                       │
          │  [ - B_total × x₂ - T_f,total × tanh(c × x₂) - T_r(α_f) ] / J_total        │
   f(x) = │  [ F_yf(α_f) + C_r × ( - x₃ + (l_r × x₄) / v ) ] / (m × v) - x₄            │
          │  [ l_f × F_yf(α_f) - l_r × C_r × ( - x₃ + (l_r × x₄) / v ) ] / I_z         │
          └                                                                            ┘

2. Ma trận véc-tơ đầu vào điều khiển B_u:
   B_u = [ 0  (1 / J_total)  0  0 ]ᵀ

3. Ma trận véc-tơ đầu vào nhiễu bẻ tay B_w:
   B_w = [ 0  (1 / J_total)  0  0 ]ᵀ


3.4.5. Tuyến tính hóa hệ thống quanh điểm cân bằng (Linearized State-Space)
--------------------------------------------------------------------------------
Khi xe vận chuyển ở dải góc đánh lái nhỏ (α_f ≈ 0, tanh(c·x₂) ≈ c·x₂, lốp chưa bão hòa F_yf ≈ -C_αf · α_f), hệ thống phi tuyến trên được tuyến tính hóa về dạng ma trận trạng thái cổ điển:

  dx/dt = A × x(t) + B_u × T_a(t) + B_w × T_d(t)

Ma trận trạng thái A (4x4) có dạng:
┌                                                                                                              ┐
│             0                                   1                          0                       0         │
│  (K_tr × C_αf × r_p) / (J_total × l_am)   - B_total / J_total   (K_tr × C_αf) / J_total   (K_tr × C_αf × l_f) / (J_total × v) │
│  (C_αf × r_p) / (m × v × l_am)                  0               - (C_αf + C_r) / (m × v)  (C_r × l_r - C_αf × l_f) / (m × v²) - 1 │
│  (l_f × C_αf × r_p) / (I_z × l_am)              0               (l_r × C_r - l_f × C_αf) / I_z - (l_f² × C_αf + l_r² × C_r) / (I_z × v) │
└                                                                                                              ┘
